Before you install

What does LuvvyLoL cost?+

The core companion and gameplay features are free. Optional paid customization may be added later, but payment is not required to use the app.

Which Mac does it support?+

The current macOS build targets Apple Silicon Macs. That includes M1, M2, M3, M4, and later Apple chips.

Does it support Swiftplay?+

Yes. LuvvyLoL supports Swiftplay loadouts and its in-game overlay works in Swiftplay, Draft, Ranked Solo/Duo, and Ranked Flex.

Where do updates come from?+

The download buttons resolve the newest published build from the official LuvvyLoL GitHub Releases page.
